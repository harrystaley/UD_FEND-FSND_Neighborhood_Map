# UD_FEND-FSND_Neighborhood_Map

## Overview

**UD_FEND-FSND_Neighborhood_Map** is an interactive web application developed as part of Udacity's Front-End Web Developer Nanodegree. The application utilizes the Google Maps API to showcase neighborhood maps with a responsive design, enabling users to explore various locations within a specified area.

## Features

- **Interactive Map**: Explore neighborhood maps with interactive markers.
- **Responsive Design**: Seamlessly adapts to different screen sizes and devices.
- **Google Maps API Integration**: Leverages the power of Google Maps for accurate and detailed map data.
- **Dynamic Content**: Updates map information dynamically based on user interactions.

## Setup and Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/UD_FEND-FSND_Neighborhood_Map.git
   ```
   
2. **Navigate to the project directory**:
   ```bash
   cd UD_FEND-FSND_Neighborhood_Map
   ```

3. **Open the `index.html` file in your web browser** to view the application.

> **Note**: You must have a valid Google Maps API key to run the application. Replace the placeholder key in the `index.html` file with your API key.

## Usage

- Open the application in your web browser.
- Use the search functionality to find specific locations within the neighborhood.
- Click on markers to view more information about each location.
